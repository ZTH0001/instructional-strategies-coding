03 · Record events & questions

Keyboard navigation — whole page

Windows and Mac: Alt means the Alt key on Windows or the Option (⌥) key on Mac. For example, Alt+1 = Option (⌥)+1 on Mac. Enter may be labelled Return (↵) on Mac. Shift (⇧), Tab (⇥), Space and arrow keys work on both. To clear a focused score on Mac, use Delete (⌫); forward Delete is not required.

Tab / Shift+Tab reach every control. Alt + arrow keys move between visible controls (text editing remains unchanged). Arrow keys move between buttons in the strategy and action toolbars; Enter / Space activates a button. Strategy buttons also support Home / End. Native dropdowns use Up / Down and Enter. Summary tables are keyboard-focusable and scroll with arrow keys.

Jump to a section: Alt+1 Session, Alt+2 Codebook, Alt+3 Coding, Alt+4 Summary, Alt+5 Save/export. Closed sections open automatically. In the coding grid, use the scoring shortcuts described below. Enter / Space opens or closes an expandable section.

Enter elapsed time since the observation started as mm:ss (e.g. 02:37 = 2 min 37 s; 120:05 = 120 min 5 s). Score every criterion: 1 = met, 0 = not met. Blank scores remain unscored. Record overlapping strategies separately. No events during a break.

In the question log, keys 1–9 select OR, PPT, ONL, OE, CE, MC, APK, CFU, OTH. Delete clears the focused score. Enter in a time field moves to the first choice. 04 · Summary

Totals use complete records only. A complete strategy event requires a valid time and every criterion scored 0 or 1. A complete question requires a valid time plus one modality, type and purpose. Incomplete records are saved and exported with their status, but excluded from totals.

Instructional strategies

Criterion met = number of complete events scored 1 for that criterion. Grey cells: criterion does not exist for that strategy. Strategy counts are separate; one episode may count for several strategies.

Questions

Question percentages use complete questions as the denominator. Each group (modality, type, purpose) adds up to 100%, subject to rounding. Only pages with complete questions are listed.
